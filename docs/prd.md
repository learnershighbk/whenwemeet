# PRD — WhenWeMeet

v1.0 · 2026-10-17 · 상세 원본: `archive/prd-v0.9-full.md`

## 1. 목적
회의 담당자가 후보 날짜·시간을 등록하고 링크를 공유하면, 참가자들이 가능한 시간을 표시하고 **가장 많이 참석 가능한 시간**을 실시간으로 확인한다.

## 2. 사용자
- **Organizer**: 이벤트를 만들고 링크를 공유한다.
- **Participant**: 링크로 들어와 이름만으로 로그인하고 가능 시간을 표시한다. (Organizer도 참가 가능)
- 데스크톱·모바일 웹.

## 3. 기능 범위
| # | 기능 | 핵심 내용 | Spec |
|---|---|---|---|
| 1 | Create Event | 회의명, 날짜(개별 클릭 / 기간), 시간대(기본 10 AM–4 PM, 1시간 간격), 타임존(기본: 시스템) | `specs/01-create-event` |
| 2 | Finalize Event | 날짜×시간 그리드, 30분(기본)/15분 단위, 불필요한 칸 회색 처리, Finalize 후 고유 URL 복사 | `specs/02-finalize-event` |
| 3 | Join Event | 이름(필수) + 비밀번호(선택) 간편 로그인 | `specs/03-join-event` |
| 4 | Availability | 내 그리드 + 전체 히트맵(그린), 칸별 가능/불가 이름, Best time, 실시간 반영 | `specs/04-availability` |

## 4. 핵심 규칙
1. Finalize 후 이벤트는 수정할 수 없다.
2. 회색 처리한 칸은 클릭할 수 없고 집계에서 빠진다.
3. Best time = 가능 인원이 가장 많은 칸 1개. 동점이면 가장 이른 칸.
4. 비밀번호 없는 이름으로 다시 들어오면 같은 사람으로 본다 (대소문자 무시). 비밀번호를 설정한 이름은 맞는 비밀번호가 있어야 들어간다.
5. 응답은 자동 저장되고, 다른 사람 화면에 2초 이내로 반영된다.
6. 시간은 이벤트 타임존 기준으로만 표시한다.

## 5. 범위 밖
회원가입·외부 로그인, 캘린더 연동, 알림, Finalize 후 수정, 이벤트/응답 삭제, 다국어.

## 6. 디자인·제약
- 단순하고 읽기 쉬운 화면. 아주 연한 쿨그레이 페이지 배경 위에 흰 카드, 근검정 텍스트·슬레이트 보조 텍스트의 모노톤 + 깊은 그린 강조색 하나. 튀는 색 없음. *(2026-10-17: 순백 배경에서 카드형으로 조정)*
- 반응형 (모바일 < 768px). 페이지 전체 가로 스크롤 없음.
- UI 문구는 쉽고 일상적인 영어.

## 7. 확정된 기본값
| 항목 | 값 |
|---|---|
| 날짜 | 오늘 이전 불가, 최대 31일 |
| 시간 | From 12 AM–11 PM, To 1 AM–12 AM(자정, 같은 날 24:00) |
| 슬롯 단위 변경 | 회색 처리 초기화 (확인 후) |
| 저장 시점 | Finalize 때 저장. 그 전엔 브라우저에만 있음 |
| 로그인 유지 | 같은 브라우저에서 이벤트별로 유지 |
| 규모 | 이벤트당 참가자 최대 100명 |
